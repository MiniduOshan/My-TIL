# 🧠 TIL: Machine Learning Basics

- 📅 **Date:** 2026-10-14

Today I learned the three main types of Machine Learning:

- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

## 📚 1. Supervised Learning

Supervised Learning is a type of Machine Learning where a model learns from **labeled data**. The training data contains inputs and their correct answers.

**Example:** Predicting house prices using previous house prices, sizes, and locations.

**Real-world applications:**
- Email spam detection
- House price prediction
- Image classification
- Student performance prediction

**Main tasks:**
- **Classification:** Predicting a category, such as spam or not spam.
- **Regression:** Predicting a numerical value, such as a house price.

## 🔍 2. Unsupervised Learning

Unsupervised Learning is a type of Machine Learning where a model learns patterns from **unlabeled data**. The correct answers are not provided during training.

**Example:** Grouping customers based on their shopping behavior without predefined customer categories.

**Real-world applications:**
- Customer segmentation
- Grouping similar documents
- Anomaly detection
- Discovering patterns in datasets

**Main tasks:**
- **Clustering:** Grouping similar data points.
- **Dimensionality Reduction:** Reducing the number of features while preserving useful information.

## 🎮 3. Reinforcement Learning

Reinforcement Learning is a type of Machine Learning where an **agent learns by interacting with an environment** and receiving rewards or penalties.

The goal is to learn actions that maximise the total reward over time.

**Example:** Training a robot to navigate a room. It receives rewards for reaching its destination and penalties for undesirable actions.

**Real-world applications:**
- Robotics
- Game-playing AI
- Autonomous systems
- Resource optimisation

**Key concepts:**
- **Agent:** The learner or decision-maker.
- **Environment:** The world in which the agent operates.
- **Action:** A decision made by the agent.
- **Reward:** Feedback received after an action.
- **Policy:** The strategy used to choose actions.

## ⚖️ Comparison

| Feature | Supervised | Unsupervised | Reinforcement |
|---|---|---|---|
| Learning approach | Learns from labeled examples | Finds patterns in unlabeled data | Learns through interaction |
| Feedback | Correct answers | No predefined answers | Rewards or penalties |
| Main goal | Predict outputs | Discover patterns | Maximize cumulative reward |
| Example | Predict house prices | Group customers | Train a robot |

## 💡 Key Takeaways

- Supervised Learning learns from examples with known answers.
- Unsupervised Learning discovers hidden patterns in data.
- Reinforcement Learning learns through actions and rewards.

Each approach solves different problems, and the best choice depends on the data available and the objective.
