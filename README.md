# 📚 Today I Learned (TIL)

> A collection of things I learn every day while exploring software engineering, web development, databases, DevOps, and computer science.

---

## 📖 About

This repository contains my **Today I Learned (TIL)** notes.

Instead of keeping random notes scattered across different platforms, I document everything here in a structured format. Each note represents something new I learned, solved, or explored during my journey as a software engineering student and developer.

The goal is simple:

- 🧠 Learn something new every day
- ✍️ Write it down in my own words
- 🚀 Build a long-term knowledge base
- 📈 Track my growth over time
