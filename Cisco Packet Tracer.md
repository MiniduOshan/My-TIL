# TIL – Cisco Packet Tracer

**Date:** 2026-10-31

Today I learned about **Cisco Packet Tracer**, a network simulation tool used to design, configure, and troubleshoot computer networks virtually.

### What I Learned

- How to create a network using routers, switches, PCs, and other networking devices.
- How to connect devices using appropriate cables.
- How to configure routers and switches using Cisco CLI.
- How to assign IP addresses and subnet masks.
- How to configure VLANs.
- How to configure default gateways.
- How to test network connectivity using `ping`.
- How to view and troubleshoot network configurations.

### Basic Cisco CLI Commands

| Command | Purpose |
|---|---|
| `enable` | Enter privileged EXEC mode |
| `configure terminal` | Enter global configuration mode |
| `hostname R1` | Change device hostname |
| `show running-config` | View current configuration |
| `show vlan brief` | View VLAN information |
| `show ip interface brief` | View interface IP addresses and status |
| `copy running-config startup-config` | Save configuration |
| `reload` | Restart the device |

### Key Concepts

- **Router:** Connects different networks.
- **Switch:** Connects devices within a local network.
- **VLAN:** Divides a physical network into separate logical networks.
- **IP Address:** Identifies a device on a network.
- **Subnet Mask:** Defines the network and host portions of an IP address.
- **Default Gateway:** Allows devices to communicate with other networks.
