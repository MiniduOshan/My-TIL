# TIL - Java Bytecode & Decompiler

**Date:** 2026-08-02

## What I Learned

Today I learned how Java executes programs and the role of **bytecode** and **decompilers**.

### Java Compilation Process

Java source code cannot be executed directly by the computer. It must first be compiled into **bytecode**, which is then executed by the **Java Virtual Machine (JVM)**.

```text
App.java
    │
    │ javac (Java Compiler)
    ▼
App.class (Bytecode)
    │
    │ JVM
    ▼
Machine Code
    │
    ▼
Program Output
```

---

## What is Bytecode?

Bytecode is the intermediate code generated by the Java compiler (`javac`). It is stored inside `.class` files.

- Platform-independent
- Executed by the JVM
- Enables Java's "Write Once, Run Anywhere" principle

Example:

```java
public class App {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

After compilation:

```bash
javac App.java
```

Java generates:

```text
App.class
```

The `.class` file contains bytecode instructions such as:

```text
0: getstatic
3: ldc
5: invokevirtual
8: return
```

These instructions are understood by the JVM, not by humans.

---

## What is a Decompiler?

A decompiler performs the opposite operation of a compiler.

```text
Compiler
Java Source (.java)
        │
        ▼
Bytecode (.class)

Decompiler
Bytecode (.class)
        │
        ▼
Java-like Source Code
```

A decompiler reads a `.class` file and reconstructs Java source code that closely resembles the original code.

### Example

Original source:

```java
System.out.println("Hello");
```

Decompiler output:

```java
System.out.println("Hello");
```

Although it looks identical, it is generated from bytecode and is **not** the original source file.

---

## Why Does `App.class` Look Like Java Code in VS Code?

When opening a `.class` file in VS Code, the editor automatically uses a decompiler (such as **FernFlower**) to display readable Java code.

The actual `.class` file is a binary file and does **not** contain Java source code.

```
App.class
      │
      ▼
FernFlower Decompiler
      │
      ▼
Readable Java Code
```

This is why the code appears similar to the original source.

---

## Compiler vs Decompiler

| Compiler | Decompiler |
|----------|------------|
| Converts Java source code into bytecode | Converts bytecode into Java-like source code |
| Used before program execution | Used for analysis and understanding compiled code |
| `App.java → App.class` | `App.class → Java-like code` |

---

## Key Takeaways

- Java source files (`.java`) are compiled into bytecode (`.class`).
- The JVM executes bytecode instead of Java source code.
- Bytecode is platform-independent.
- A decompiler reconstructs readable Java code from bytecode.
- VS Code automatically decompiles `.class` files using FernFlower.
- Decompiled code is generated and may not exactly match the original source.

## Commands Learned

Compile Java source:

```bash
javac App.java
```

Run compiled program:

```bash
java App
```

View bytecode instructions:

```bash
javap -c App.class
```
